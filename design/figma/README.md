# 《镇夜局：纸门》Figma 设计稿

## 导入方法

1. 打开 Figma Design 文件。
2. 将 `zhenyeju-figma-board.svg` 拖入画布，或使用 **File → Place image**。
3. 导入后执行一次 Ungroup，即可分别编辑页面、文字与图形。

## 页面清单

- 01 启动页
- 02 第一幕：残符归位
- 03 第二幕：三铃镇尸
- 04 第三幕：纸门照影
- 05 游戏内提示状态
- 06 超时失败与复活
- 07 激励广告倒计时
- 08 章节结局

## 设计规范

- 基准画布：750 × 1334，适配微信小游戏竖屏。
- 主背景：`#071418`、`#171D1A`、`#050606`。
- 主文字：`#F0DFBD`；次级文字：`#A38F73`。
- 危险色：`#A5362D`；主要按钮：`#712119`。
- 奖励/提示色：`#FFCB65`；冷光强调：`#72B9B6`。
- 默认字体：PingFang SC / Microsoft YaHei / 系统无衬线字体。
- 交互热区建议不小于 88 × 88 设计像素。
- 顶部状态、底部磁带记录保持跨关卡一致，降低学习成本。

## 设计方向

延续现有 Canvas 版本的中式民俗恐怖基调，同时增强层级、交互反馈和谜题可读性。所有主操作采用旧漆朱红，线索与奖励采用铜金色，危险临近时通过边缘暗红渐晕表达，而不是遮挡谜题主体。
