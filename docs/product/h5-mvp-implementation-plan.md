# 《镇夜司：五行锁》H5第一版落地方案

## 1. 第一版目标

第一版不是一次制作完整七关，而是交付一个能验证核心体验的H5垂直切片：

- 序章「阴阳义庄」。
- 第一关「青木风廊」。
- 两个房间连续切换。
- 跨设备加工和跨房间物品。
- 阴阳、震巽和五行生克谜题。
- 僵尸接近、撞门、破门和死亡重试。
- 横屏与竖屏布局。
- 完整开始、通关、失败和检查点流程。

第一版预计体验时间为12–20分钟。其目标是验证：玩家是否愿意探索、能否理解文化规则、僵尸压力是否紧张但不妨碍推理，以及古风视觉是否具备继续开发价值。

## 2. 技术路线

第一版沿用现有轻量Canvas H5运行层，原因如下：

- 无需安装大型引擎即可快速上线验证。
- 当前输入、音频、存储、构建和服务器部署链路已经可用。
- 状态机保持平台无关，后续可以迁移到Cocos Creator。
- 先验证关卡和交互，再决定是否投入Cocos场景与动画重制。

代码按未来迁移需要拆分为：

```text
GameState             纯状态机、谜题依赖、威胁时间和检查点
MainRenderer          房间、UI、近景机关、特效
InteractionLayer      点击、拖拽、物品投放
Audio                 环境和反馈音
Platform              存档、震动、微信适配
```

## 3. MVP关卡流程

### 3.1 阴阳义庄

```text
检查供桌
→ 获得白玉片与油灯
→ 检查铜镜，取得黑玉片并惊醒棺中尸
→ 油灯放入日灯装置
→ 黑白玉片放入照影台
→ 调整日灯与月镜方向
→ 投影显出暗格
→ 取得太极铜钥
→ 开启东门
```

### 3.2 青木风廊

```text
检查东方窗格
→ 获得震卦木片
→ 根据竹帘摆动敲响风铃
→ 获得巽风丝带
→ 从水缸取得引水瓢
→ 将太极轴芯、震卦木片和巽风丝带装入木枢
→ 调整水路避开金属管道
→ 启动根系机关
→ 获得青木门印
→ 开启下一道门，结束MVP
```

## 4. 僵尸威胁规则

- 进入房间后先提供自由观察期。
- 阴阳义庄在取得黑玉片时启动威胁。
- 青木风廊在第一次敲响风铃时启动威胁。
- 错误操作会缩短剩余时间。
- UI不显示精确秒数，只显示“寂静、接近、撞门、破门”阶段。
- 时间耗尽进入死亡界面，可从当前房间检查点重试。
- 房间重试保留已经学习的文化图鉴，但重置本房间物品和机关。

## 5. 美术落地

- 封面使用 `01-key-art.webp`。
- 阴阳义庄使用 `02-yinyang-mortuary-room.webp`。
- 青木风廊使用 `03-wood-wind-corridor.webp`。
- UI参考 `04b-landscape-ui-refined.webp`，实际由Canvas绘制，确保中文准确和触控区域清晰。
- AI图中的卦象只作为概念参考，互动卦象由代码重新绘制。

## 6. 实施阶段

### 阶段A：状态机

- 重写两房间进度状态。
- 增加物品、投放、机关结果和威胁时间。
- 增加死亡、重试和检查点。
- 编写全通关和失败路径测试。

### 阶段B：场景与交互

- 接入三张最终背景。
- 建立房间热点与近景设备。
- 实现物品栏拖拽和投放反馈。
- 实现文化规则的可视化机关。

### 阶段C：威胁与反馈

- 门板裂纹、棺盖震动和远处僵尸影子。
- 噪声惩罚、威胁阶段和死亡遮罩。
- 机关成功粒子和音效。

### 阶段D：适配与发布

- 状态机单元测试。
- H5构建。
- 横屏完整通关。
- 竖屏热点和物品栏验证。
- 控制台错误检查。
- 公网部署和最终回归。

## 7. 第一版验收标准

- 可从封面开始连续完成两个房间。
- 至少包含6次有效物品投放。
- 至少包含2个需要理解文化关系的设备谜题。
- 僵尸威胁能够正常启动、推进、导致死亡并重试。
- 重试不会卡死或带入错误房间状态。
- 横屏与竖屏均可点击和拖拽。
- 中端浏览器无持续控制台错误。
- H5静态包可以部署到现有服务器。

## 8. 后续升级到Cocos的条件

满足以下条件后再迁移：

- 盲测玩家完成率达到60%以上。
- 至少70%的玩家能复述阴阳或五行规则。
- 玩家认为僵尸压力“紧张但公平”的比例超过60%。
- 平均单房间时长落在8–15分钟。
- 美术方向获得继续制作五行全章节的认可。
