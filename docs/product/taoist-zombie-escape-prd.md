# 《镇夜司：五行锁》产品需求与关卡设计文档

> 文档版本：V1.0
> 产品形态：微信小游戏 / H5 / 后续可扩展为多端小游戏
> 推荐引擎：Cocos Creator 3.x LTS + TypeScript
> 核心类型：国风志怪密室逃脱 + 道家文化解谜 + 僵尸逼近生存压力

---

## 1. 产品概述

### 1.1 产品名称

正式候选名：**《镇夜司：五行锁》**

备选名：

- 《玄门夜行录》
- 《八门镇夜》
- 《五行义庄》
- 《符门之后》

宣传语：**一夜六门，破阵求生。**

### 1.2 产品定位

《镇夜司：五行锁》是一款面向微信小游戏用户的章节式密室逃脱游戏。玩家被困在一座架空东方志怪世界中的封禁建筑内，需要在僵尸破门前探索房间、收集物件、学习文化知识、操作古代机关，并通过阴阳、五行、八卦和虚构符箓规则完成推理，取得通往下一房间的钥匙。

产品不是知识问答游戏，也不是单纯寻找数字密码，而是把文化知识直接转化为机关规则：

- 阴阳决定机关的平衡、互换和显隐。
- 五行生克决定物件加工、路线选择和机关反馈。
- 八卦的卦象、方位与自然意象决定门、灯、风、水、火等环境机关。
- 符箓以虚构化的“结构语言”出现，用于拼合、校准和封禁，不复制真实宗教仪轨。
- 僵尸威胁为解谜提供节奏与取舍，但不压缩玩家最初的观察时间。

### 1.3 核心卖点

1. **中国传统文化成为玩法规则**：玩家不是观看装饰，而是必须理解知识才能推进。
2. **房间—设备—门锁的关系链**：每关包含探索、加工、推理、开门四个阶段。
3. **渐进式僵尸压力**：声音、门板、影子和破门过程形成可读的危险阶段。
4. **国风志怪视觉辨识度**：漆木机关、青铜构件、宣纸、朱砂、八卦盘与古建筑空间统一呈现。
5. **知识图鉴与二次理解**：谜题完成后解锁简短文化卡片，帮助玩家理解而非死记答案。

### 1.4 文化表达边界

- 世界观为架空志怪题材，不宣称符箓、法术或镇尸方法在现实中有效。
- 所有可操作符箓均采用原创结构和虚构文字，不复刻现实宗教法事文本。
- 避免把道家思想简化成单纯驱鬼工具；阴阳与五行重点表现变化、制约、平衡与循环。
- 僵尸造型采用非写实、低血腥方式，减少肢体破坏和视觉刺激。
- 文化知识需在正式制作前邀请传统文化顾问或相关研究者复核。

## 2. 目标用户与使用场景

### 2.1 核心用户

- 16–35岁，喜欢密室逃脱、剧情解谜和国风美术的玩家。
- 接受轻度惊悚，但不追求重度血腥或高强度战斗。
- 喜欢《纸嫁衣》式民俗氛围、房间探索、物件组合和剧情反转的用户。
- 对五行、八卦、古代机关、志怪故事感兴趣，但不一定具有专业知识。

### 2.2 次级用户

- 喜欢微信小游戏短时体验和章节收集的轻度玩家。
- 国风内容创作者、解谜主播及情侣/朋友共同讨论通关的用户。
- 希望通过游戏接触传统文化基础概念的年轻玩家。

### 2.3 体验时长

- 单房间：8–15分钟。
- 单章节：45–75分钟，由5个五行房间、1个序章和1个终局组成。
- 微信小游戏单次会话目标：10–20分钟。
- 支持在进入新房间时自动存档。

### 2.4 难度分层

- **故事模式**：威胁推进较慢，连续失败后自动延长时间，提示更明确。
- **标准模式**：正常威胁速度，提示分为三档。
- **夜行模式**：部分线索位置随机，错误操作会制造更大噪声，僵尸推进更快。

## 3. 世界观与剧情框架

### 3.1 世界背景

架空王朝末年，城外的“镇夜司”负责封存受到阴气侵染的器物、尸身与古代机关。一次五行封禁失衡后，整座建筑在子时关闭，沉睡的守门尸逐层苏醒。

玩家扮演刚入门的守夜学徒“陆隐”。师父失踪，只留下六枚残缺门印和一本没有写完的《五行锁录》。玩家必须在天亮前穿过义庄、丹房、坛室、剑阁、井庭和八门中枢，恢复五行循环，并查明师父是否主动打开了封禁。

### 3.2 章节悬念

- 师父留下的线索既像救援，也像刻意引导玩家进入最深处。
- 每个房间都有一段不同版本的值夜记录，彼此存在矛盾。
- 玩家逐渐发现僵尸并非单纯追杀，而是在阻止某件东西离开中枢。
- 最终选择决定玩家是重新封禁、释放中枢中的意识，还是继承镇夜司。

### 3.3 叙事载体

- 值夜记录、竹简、拓片和机关铭牌。
- 房间状态变化和僵尸行为。
- 经过设备加工后显现的隐藏信息。
- 师父留下的残缺门印。
- 通关后的文化图鉴与剧情档案。

## 4. 核心玩法

### 4.1 主循环

```text
进入房间
→ 自由观察环境
→ 找到原始线索与可携带物
→ 检查、翻面、拆解和组合
→ 使用房间核心设备加工线索
→ 学习并应用文化规则
→ 获得钥匙或门印
→ 在僵尸破门前开启下一道门
```

### 4.2 双轨压力结构

每个房间同时运行两条进程：

#### 解谜进程

- 发现文化规则。
- 获得可加工物品。
- 启动核心设备。
- 形成最终门锁答案。

#### 威胁进程

- 环境出现远处脚步和铃铛声。
- 僵尸抵达入口并开始撞门。
- 门板破裂，房间机关受到震动干扰。
- 僵尸进入，转为短暂追逐。

### 4.3 威胁阶段

| 阶段 | 表现 | 玩家可采取的行动 |
| --- | --- | --- |
| 安静期 | 无明确倒计时，仅有远处声音 | 自由观察和建立空间认知 |
| 接近期 | 脚步、影子、门把转动 | 关闭噪声源、准备堵门物件 |
| 撞门期 | 门板震动、灰尘掉落、音乐加速 | 堵门、贴临时门印、制造诱饵 |
| 破门期 | 手臂伸入、灯光闪烁 | 完成最后机关或进入藏身点 |
| 追逐期 | 僵尸进入房间，约15–25秒 | 推倒障碍、使用一次性道具、开门逃生 |

威胁计时不在玩家进入房间时立刻启动，而是在玩家触发关键事件后启动，例如启动丹炉、敲响铜钟、打开棺盖或接通水闸。

### 4.4 物品交互

- 单击：拾取、查看或进入设备近景。
- 拖动：放入设备、覆盖图案、组合物件、用于门锁。
- 双指旋转或旋转按钮：调整卦盘、镜片、符片和机关轮。
- 翻面：查看物件背面、夹层和反向文字。
- 拆解：移除钉子、绳结、外壳或封泥。
- 组合：将零件、残片、药材、门印等合成为新物件。

### 4.5 文化学习机制

文化知识采用“三步学习”：

1. **环境暗示**：壁画、方位、颜色和器物呈现规则。
2. **操作验证**：玩家在机关上尝试，系统通过环境变化反馈对错。
3. **通关归纳**：完成谜题后解锁不超过120字的知识卡片。

提示系统不直接显示完整答案：

- 一级提示：指出需要观察的区域。
- 二级提示：说明应使用的文化关系。
- 三级提示：给出具体操作方向。

## 5. 文化知识体系

### 5.1 阴阳

核心表达：对立、依存、转化与动态平衡。

游戏化方式：

- 黑白物件需要互补而不是全部变成同一种状态。
- 光与影共同组成完整图案。
- 阴面显示隐藏信息，阳面提供操作顺序。
- 机关在两种状态间转换，正确答案通常是平衡点而非极值。

### 5.2 五行生克

相生：

```text
木生火 → 火生土 → 土生金 → 金生水 → 水生木
```

相克：

```text
木克土 → 土克水 → 水克火 → 火克金 → 金克木
```

游戏化方式：

- 决定物件应该进入哪台设备。
- 决定处理危险机关的方法。
- 决定五行路线、门印顺序与资源取舍。
- 让同一物品既可能帮助机关，也可能抑制威胁。

### 5.3 八卦

| 卦 | 卦象 | 自然意象 | 方位 | 主要关卡用途 |
| --- | --- | --- | --- | --- |
| 乾 | ☰ | 天 | 西北 | 完整阳线、顶部机关、刚健结构 |
| 坤 | ☷ | 地 | 西南 | 完整阴线、承载、地面压力机关 |
| 震 | ☳ | 雷 | 东 | 启动、震动、鼓和机关触发 |
| 巽 | ☴ | 风 | 东南 | 风向、穿透、风铃和通风结构 |
| 坎 | ☵ | 水 | 北 | 水路、陷阱、镜面与深度 |
| 离 | ☲ | 火 | 南 | 火焰、光照、显影和炉温 |
| 艮 | ☶ | 山 | 东北 | 停止、封闭、石门和阻挡 |
| 兑 | ☱ | 泽 | 西 | 声音、开口、铜铃和共鸣 |

### 5.4 符箓视觉语法

游戏中的符箓为原创虚构系统，由四种可读结构构成：

- **符首**：标识所属五行或房间。
- **符脉**：表示能量流向和连接关系。
- **符结**：表示需要对齐的机关节点。
- **符脚**：表示最终落点或封禁方向。

玩家的主要操作是拼合、覆盖、旋转和校准，不要求模仿现实画符仪式。

## 7. 详细关卡设计

## 7.1 序章：阴阳义庄

### 关卡目标

从停尸义庄中找到太极铜钥，打开东侧木门。

### 文化知识点

- 阴阳并非简单善恶，而是互补、转化和共同构成整体。
- 光为阳、影为阴；两者重叠后才形成完整信息。
- 太极图需要黑白两枚残片共同归位。

### 视觉设计规范

- 主色：墨黑、骨白、暗朱砂、旧木褐。
- 空间：中轴对称义庄，中央棺台，左右日灯与月镜。
- 材质：漆木棺、宣纸灯、青铜镜、灰尘与冷月光。
- 僵尸：位于远处棺内，仅以指甲刮木和棺盖震动表现。
- UI：黑白太极状态环，威胁状态用朱砂裂纹呈现。

### 解谜关系链

1. 玩家检查供桌，取得半枚白色鱼形玉片和一支熄灭的油灯。
2. 检查棺台阴影，发现阴影内有无法直接读取的门纹。
3. 从铜镜背面拆下半枚黑色鱼形玉片。
4. 将两枚玉片放入日月照影台，组成太极轮廓。
5. 调整日灯和月镜，使白片被暖光照亮、黑片进入冷影。
6. 完整门纹投射到棺台侧面的暗格上。
7. 按照投影轮廓推动暗格机关，取得太极铜钥。

### 僵尸压力

日灯被点亮后，中央棺内的守门尸开始苏醒。玩家可以用供桌压住棺盖，延缓30秒，但供桌移动后会遮挡部分投影，需要在解谜效率和安全之间选择。

### 过关判定

- 黑白玉片均放入照影台。
- 日灯与月镜状态正确。
- 暗格门纹完整投射。
- 玩家取得太极铜钥并用于东侧木门。

### 失败判定

- 守门尸完全推开棺盖并接触玩家。
- 追逐阶段结束前未打开东侧木门。

## 7.2 第一关：青木风廊

### 关卡目标

启动风雷木枢，让枯藤重新生长并托出青木门印。

### 文化知识点

- 木对应东方与生发。
- 震为雷，方位在东；巽为风，方位在东南。
- 风助生长，雷代表启动；水生木，金克木。

### 视觉设计规范

- 主色：黛青、竹绿、孔雀蓝、少量雷光紫。
- 空间：半露天回廊，竹帘、风铃、木质根系机关和东方窗格。
- 机关：根系像机械管道一样贯穿墙体，节点带青铜包边。
- 光线：东方冷晨光穿过竹帘，雷雨在远处闪烁。
- 符号：震卦与巽卦以木刻纹样呈现，不直接显示文字答案。

### 解谜关系链

1. 玩家从东方窗框取得一枚刻有三条线的木片，背面标有雷纹。
2. 吹动东南角竹帘，发现风向会让三组风铃依次发声。
3. 根据声音长短，把木片的三条线调整为震卦结构。
4. 将序章获得的太极铜钥作为轴芯，装入风雷木枢。
5. 风铃提供“巽”的风向，木片提供“震”的启动结构，两者共同启动根系。
6. 根系仍然枯萎，需要从破裂水缸中引水；玩家必须避开带有金属碎片的错误管道，因为金克木。
7. 水流进入根系后，青藤生长并托出青木门印。

### 僵尸压力

敲响错误风铃会产生噪声，加速走廊尽头的僵尸接近。玩家可剪断一组风铃作为诱饵扔入侧廊，但剪断后将失去一次声音提示。

### 过关判定

- 震卦木片结构正确。
- 风向设置为东南入风。
- 水流避开金属管道并进入根系。
- 青藤完成生长，青木门印被拾取并嵌入下一门。

## 7.3 第二关：离火丹房

### 关卡目标

控制三才丹炉温度，用上一关的青木门印引火，铸出赤火钥胚。

### 文化知识点

- 离卦为火，卦象为阳—阴—阳。
- 火对应南方与光明、显现。
- 木生火，水克火；火不是越旺越好，而要保持可控状态。

### 视觉设计规范

- 主色：朱红、赭红、金橙、炭黑。
- 空间：高挑丹房，中央三层铜炉，南墙有可开闭采光窗。
- 机关：三层炉门对应离卦三爻；中层必须保留空隙。
- 特效：火星、热浪、烟尘和宣纸显影，不出现夸张爆炸。
- 僵尸：炉后药柜中的药尸被热量唤醒，动作僵硬且带灰烬。

### 解谜关系链

1. 玩家在南墙找到三块炉门挡板，其中两块完整、一块中空。
2. 根据离卦“阳—阴—阳”的结构，把完整挡板装在上下层，中空挡板装在中层。
3. 将青木门印放入下层作为引火材料，验证木生火。
4. 开启南窗，使阳光照在温度刻度上，显现安全炉温范围。
5. 调节风门升温；若炉温过高，使用房间水罐抑制，体现水克火。
6. 将无字符纸置于炉旁显影架，受热后出现钥胚模具图。
7. 按照显影图调整铜液导槽，压下炉柄，铸出赤火钥胚。

### 僵尸压力

丹炉启动后产生持续噪声，药柜中的药尸进入苏醒倒计时。玩家可以降低炉温减少噪声，但铸造时间会变长；也可以高温快速铸造，但需要处理火焰失控风险。

### 过关判定

- 三层炉门构成正确离卦。
- 炉温连续保持在安全范围内指定时间。
- 符纸完成显影，导槽与图案一致。
- 赤火钥胚成功铸造并冷却后取出。

---

## 7.4 第三关：厚土坛室

### 关卡目标

修复五方镇坛，利用土生金将赤火钥胚压制成黄土钥模。

### 文化知识点

- 土象征承载、稳定与居中协调。
- 坤为地，艮为山；坤侧重承载，艮侧重停止。
- 火生土、土生金、木克土、土克水。

### 视觉设计规范

- 主色：土黄、赭石、暗棕、青灰石色。
- 空间：方形地下坛室，中心高台，四角石兽和五色土槽。
- 构图：中心稳定、低重心，地面机关形成明显十字与中心点。
- 机关：压力板、石磨、模具和山形止动块。
- 僵尸：被埋在坛下的尸手会从错误压力板周围伸出，不直接大量流血。

### 解谜关系链

1. 玩家用丹房灰烬拓印地面，显出五个隐藏压力点。
2. 中心点代表土，其余四点需要根据房间壁画的方位放入对应色土。
3. 玩家将赤火钥胚放入中心模具，验证火生土的前序关系。
4. 旋转坤卦承载盘，使六条断线朝下承托模具。
5. 将艮卦山形止动块放入石磨上方，使压制过程在正确高度停止。
6. 若水槽泄漏，必须用土槽封住水路，体现土克水。
7. 石磨完成压制，赤火钥胚形成带有土纹定位槽的黄土钥模。

### 僵尸压力

踩错压力点会唤醒坛下尸手并锁住玩家短时间。连续三次错误会使西侧土墙崩裂，僵尸开始进入。玩家可用木梁支撑墙体，但木克土，会使中央坛盘短暂失衡。

### 过关判定

- 五个压力点放置正确。
- 坤盘与艮止动块状态正确。
- 水路被封，中心模具稳定。
- 黄土钥模压制完成。

---

## 7.5 第四关：庚金剑阁

### 关卡目标

利用铜钟共鸣和镜面反射，从黄土钥模中锻成白金剑钥。

### 文化知识点

- 金对应西方、收敛、切割与规则。
- 乾为天，三条阳线；兑为泽，上方开口，亦可联系声音与悦。
- 土生金、金生水、火克金、金克木。

### 视觉设计规范

- 主色：冷银、墨蓝、铁黑、少量白金高光。
- 空间：纵深剑阁，悬挂八枚铜钟，西墙排列镜面与剑架。
- 机关：铜钟、共鸣弦、金属反光板和磨剑轮。
- 光线：窄束冷光形成锐利方向线，避免大量镜面炫光影响可读性。
- 僵尸：盲眼守阁尸依靠声音定位，强化“声音既是线索也是危险”的冲突。

### 解谜关系链

1. 玩家将黄土钥模放入锻台，启动土生金的加工环节。
2. 查看西墙兑卦纹样，发现上方断开，对应需要保留的高音空位。
3. 按照乾卦三阳线敲响三枚低音铜钟，建立稳定共鸣基音。
4. 再根据兑卦上缺结构敲击两枚高音钟，中间保留一次静默。
5. 共鸣使金属镜片震动，反射光在剑架后组成完整虚构符脉。
6. 玩家旋转镜片，使符脉落在黄土钥模的定位槽上。
7. 启动磨剑轮，把钥模锻成细长白金剑钥。

### 僵尸压力

守阁尸会被钟声吸引。玩家可以拉动远端空钟制造假声源，但会失去一枚可用于校音的钟。错误连续敲击会直接推进威胁阶段。

### 过关判定

- 乾、兑两组节奏正确。
- 镜片反射形成连续符脉。
- 符脉与钥模定位槽重合。
- 白金剑钥完成锻造并用于开启井庭门。

---

## 7.6 第五关：玄水井庭

### 关卡目标

利用白金剑钥开启水闸，调整九曲水盘，取得玄水门珠。

### 文化知识点

- 水对应北方、流动、下行、深度与映照。
- 坎卦为阴—阳—阴，中心阳线被两侧阴线包围。
- 金生水、土克水、水生木、水克火。

### 视觉设计规范

- 主色：玄黑、靛蓝、青蓝、月白。
- 空间：露天井庭，中央古井，地面九曲水道和北墙水门。
- 机关：水盘、浮子、反射镜、水闸和深浅刻度。
- 光线：月光倒影承担主要谜题提示，水面信息需要稳定后才能读取。
- 僵尸：水尸从不同水渠接近，速度与玩家选择的水路有关。

### 解谜关系链

1. 使用白金剑钥打开北墙金属水闸，验证金生水。
2. 水进入九曲水盘，但被三块土塞阻挡；移除全部土塞会淹没房间，只能移除正确两块。
3. 依据坎卦阴—阳—阴结构，将两侧水道设为浅、中间水道设为深。
4. 水面稳定后，月影在盘中形成倒置符结。
5. 玩家必须通过铜镜查看反射，将倒置符结还原为正确方向。
6. 根据五行相生顺序，让水最终流向东方木槽，而不是南方火槽。
7. 木槽中的莲形浮子升起，托出玄水门珠。

### 僵尸压力

错误开闸会把水尸引入房间。玩家可暂时关闭水路阻挡水尸，但谜题信息也会随水面消失。追逐阶段中，水位会降低移动速度。

### 过关判定

- 金属水闸开启。
- 九曲水盘形成正确坎卦深浅结构。
- 反射符结方向正确。
- 水流最终进入东方木槽。
- 玄水门珠被取得。

## 7.7 终局：太极八门中枢

### 关卡目标

将五行门印和八卦方位归位，恢复封禁循环，取得中枢总钥并决定最终结局。

### 文化知识点

- 五行不是单向排列，而是持续相生并互相制约的循环。
- 八卦需要同时结合卦象、方位与自然意象。
- 阴阳平衡不是静止不动，而是在变化中保持整体稳定。

### 视觉设计规范

- 主色：墨黑、象牙白、旧金、朱砂，五行颜色作为局部能量轨迹。
- 空间：大型圆形中枢，八门环绕，中心太极盘分为上下两层。
- 机关：五行门印槽、八卦门、太极平衡臂、符箓拼合台。
- 光线：每归位一项，房间对应方位亮起，最终形成完整循环光路。
- 僵尸：此前所有守门尸在外环出现，但不会同时进入；玩家通过八门状态改变其路线。

### 解谜关系链

1. 将青木、赤火、黄土、白金、玄水五件核心物放入相生顺序槽。
2. 五行循环点亮后，八扇门显示不同自然现象：天、地、雷、风、水、火、山、泽。
3. 根据前五关学习的方位，把八卦门旋转到正确位置。
4. 中央太极盘仍然失衡，玩家需要把序章的黑白玉片分别放在阴阳盘上。
5. 五行能量过强的一侧必须通过相克关系进行制衡，不能只追求全部点亮。
6. 六个房间收集到的虚构符箓残片在拼合台上组成完整符脉。
7. 符脉投射到中心太极盘，生成中枢总钥。
8. 玩家选择将总钥插入“封”“启”或“承”三个钥位之一，触发不同结局。

### 僵尸压力

终局没有固定倒计时。玩家每次错误归位都会打开一扇错误的门，使守门尸距离中心更近。可以通过调整正确的艮门使某一路停止，或通过巽门改变风向转移声音。

### 过关判定

- 五行相生顺序正确。
- 八卦方位全部归位。
- 阴阳盘达到动态平衡区间。
- 虚构符脉完整连接。
- 玩家使用中枢总钥选择结局。

### 结局设计

- **封**：重新封闭中枢，玩家成为新的守夜人。
- **启**：释放中枢中的意识，揭示师父计划，进入下一章节。
- **承**：玩家接纳五行门印力量，但自身出现尸化征兆。

## 8. 视觉设计规范

### 8.1 总体风格

关键词：

```text
国风志怪、2.5D微缩场景、古代机关、漆木、青铜、宣纸、朱砂、冷月光、非写实僵尸、电影级体积光
```

表现方式：

- 场景采用3D渲染式2.5D固定镜头，兼顾质感和微信小游戏性能。
- 构图保持房间出口、核心设备和威胁入口清晰可读。
- 文化符号融入机关结构，不把八卦和符纸作为无意义贴图。
- 游戏内所有中文由程序字体渲染，AI概念图不承担最终文字显示。
- 僵尸保持低血腥：灰白皮肤、旧布衣、僵直动作、纸符和阴影，不表现大量创口。

### 8.2 五行色彩规范

| 元素 | 主色 | 辅色 | 材质 |
| --- | --- | --- | --- |
| 木 | 黛青、竹绿 | 雷紫、青铜 | 木刻、竹、藤蔓 |
| 火 | 朱红、金橙 | 炭黑、暗金 | 铜炉、炭、红漆 |
| 土 | 土黄、赭石 | 青灰、旧铜 | 石、陶、夯土 |
| 金 | 冷银、铁黑 | 月白、深蓝 | 铜钟、剑、镜片 |
| 水 | 玄黑、靛蓝 | 青蓝、月白 | 水面、湿石、铜闸 |
| 中枢 | 黑白、旧金 | 五行流光、朱砂 | 太极石盘、金属嵌线 |

### 8.3 UI规范

- 主UI像压在画面边缘的窄宣纸签，不遮挡机关。
- 物品栏使用漆木格与青铜包角。
- 文化图鉴使用线装书视觉，卦象必须清晰可辨。
- 威胁指示不使用普通红色进度条，而是表现为门板裂纹、朱砂线断裂和铃铛震动。
- 提示按钮采用“观”“悟”“解”三级状态，分别对应三档提示。
- 横屏UI位于右侧，竖屏UI收纳到底部抽屉。

### 8.4 动效规范

- 机关运动强调重量、摩擦和机械停顿。
- 朱砂符脉点亮使用沿线流动效果，不使用现代霓虹灯风格。
- 卦盘转动每45度产生明确卡点反馈。
- 僵尸接近通过局部影子、布帘移动和门板震动逐步升级。
- 成功反馈控制在1–2秒，避免长动画中断推理。

### 8.5 音频规范

- 环境：风、木梁、滴水、纸张、铜器余音、远处脚步。
- 音乐：埙、古琴泛音、低频鼓点和极弱人声气息，避免持续高强度恐怖音墙。
- 五行分别建立声音记忆：木为竹与木鱼，火为炉风，土为沉石，金为铜钟，水为滴水与回声。
- 僵尸威胁用声音方向帮助玩家判断入口位置。

## 9. 技术实现要求

### 9.1 技术栈

- Cocos Creator 3.x LTS。
- TypeScript。
- 2D UI + 2.5D固定镜头场景。
- 微信小游戏作为首发平台，H5作为快速测试和分享平台。
- 可选后端：微信云开发或轻量Node服务，用于存档、统计和活动配置。

### 9.2 推荐模块

```text
GameBootstrap
├─ SceneFlowController       房间加载、门切换、转场
├─ PuzzleGraphEngine         数据驱动谜题依赖图
├─ InventorySystem           拾取、查看、组合、消耗
├─ InteractionController     点击、拖动、旋转、翻面
├─ RoomStateStore            房间永久状态和回溯
├─ ThreatDirector            僵尸阶段、噪声、堵门、追逐
├─ KnowledgeCodex            文化知识卡片与复习
├─ HintSystem                三级提示
├─ SaveService               本地/云端存档
├─ AudioDirector             环境、机关、威胁分层音频
└─ AnalyticsService          漏斗、卡点和失败原因统计
```

### 9.3 数据驱动谜题模型

每个谜题节点至少包含：

```json
{
  "id": "fire_furnace_li_trigram",
  "roomId": "fire_alchemy_room",
  "prerequisites": ["wood_token_inserted", "south_window_open"],
  "inputs": ["upper_plate", "middle_hollow_plate", "lower_plate"],
  "rule": "LI_TRIGRAM",
  "successEffects": ["furnace_enabled", "knowledge_li_unlocked"],
  "failureEffects": ["noise_add_10", "heat_add_5"],
  "hintIds": ["fire_hint_1", "fire_hint_2", "fire_hint_3"]
}
```

谜题规则、文案、物品依赖和成功效果应配置化，避免每关全部硬编码。

### 9.4 房间资源结构

```text
RoomPrefab
├─ BackgroundLayer
├─ ArchitectureLayer
├─ DeviceLayer
├─ ItemLayer
├─ ThreatEntranceLayer
├─ ForegroundOcclusion
├─ LightingAndVFX
├─ InteractionHotspots
└─ RoomAudioZones
```

### 9.5 性能目标

- 中端安卓设备稳定30FPS，主流设备目标60FPS。
- 同屏活动机关数量控制在20个以内。
- 单房间核心纹理建议不超过4张2048级图集，实际按设备分级加载。
- 使用WebP/平台支持的压缩纹理，避免大量独立透明大图。
- 首包仅包含序章与公共系统，其余房间采用分包或远程资源。
- 音频按场景分包，长环境音使用压缩格式，关键反馈使用短音效。
- 内存目标以中端机型实测为准，场景切换后主动释放上一个房间的大纹理与音频。

### 9.6 适配要求

- 设计基准：横屏16:9，同时提供竖屏9:16布局。
- 横屏：场景占左侧约75%，物品栏和记录位于右侧。
- 竖屏：场景占上方55%–65%，底部为可收起物品抽屉。
- 关键交互区域最小触控尺寸不低于44逻辑像素。
- 刘海、圆角和底部手势区域使用安全区适配。

### 9.7 存档与失败恢复

- 进入新房间自动建立检查点。
- 房间内死亡后保留已解锁文化图鉴，但重置本房间消耗品和机关状态。
- 连续失败两次后，故事模式自动延长威胁时间。
- 重新进入游戏时恢复到最近房间入口，不恢复追逐中的瞬时状态。

### 9.8 埋点要求

- 房间进入、离开、完成耗时。
- 每个谜题首次操作、错误次数、提示使用等级。
- 玩家死亡时的威胁阶段和已完成节点。
- 道具组合失败组合排行。
- 每扇门的玩家流失率。
- 不同模式选择和章节结局选择。

## 10. 内容生产与验收

### 10.1 单关制作流程

1. 文化知识审核。
2. 纸面谜题与关系图设计。
3. 无美术灰盒原型。
4. 3–5名目标玩家盲测。
5. 调整线索可读性与错误反馈。
6. 场景概念图和分层美术制作。
7. Cocos机关与威胁系统实现。
8. 横竖屏视觉QA。
9. 性能、包体和低端机测试。
10. 文化顾问复核后发布。

### 10.2 关卡验收标准

- 玩家不看提示能在90秒内发现第一个有效行动。
- 至少70%的测试玩家能理解本关核心文化关系，而非只记住密码。
- 每个关键道具至少经过一次检查、加工或组合，不出现纯粹捡钥匙。
- 至少一次跨设备信息转换。
- 至少一个可选的延缓僵尸策略。
- 失败原因明确，死亡后重试成本不超过30秒。
- 正确操作有环境级反馈，不能只弹出“成功”文字。
- 文化图案、卦象与方位在视觉上准确且可辨认。

### 10.3 MVP范围

第一阶段只实现：

- 序章“阴阳义庄”。
- 第一关“青木风廊”。
- 公共物品栏、设备近景、提示、威胁阶段和房门切换。
- 2个可跨房间使用的物件。
- 1段完整死亡和房间检查点流程。
- 横竖屏适配。

MVP通过盲测后，再制作火、土、金、水和终局。
