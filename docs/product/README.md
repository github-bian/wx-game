本目录保存从旧原型转向“国风道家密室逃脱 + 僵尸生存压力”方向的产品设计成果。H5垂直切片已经落地，当前可玩范围为序章「阴阳义庄」与第一关「青木风廊」。

## 产品结构

- 序章：阴阳义庄
- 第一关：青木风廊
- 第二关：离火丹房
- 第三关：厚土坛室
- 第四关：庚金剑阁
- 第五关：玄水井庭
- 终局：太极八门中枢

每关都遵循“房间探索 → 设备加工 → 文化推理 → 获得钥匙 → 僵尸逼近 → 开门逃生”的核心循环。
