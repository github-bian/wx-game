# 第一章：给还记得的人

## 体验目标

- 单一毛毡邮局房间，10–15 分钟完成。
- 画面里的材质、缺口、光线和物件关系就是谜面。
- 不出现任务清单；玩家通过触摸、翻面、拖动、旋转和重叠物件理解规则。
- 所有谜题串成一条因果链，解开后永久改变房间状态。

## 谜题链

1. **夜班记录**：翻看记录背面的三枚月相针脚，发现缺口方向“下、右、左”。
2. **三环月灯**：旋转三层毛毡月环复现缺口方向，紫色月灯点亮。
3. **无名退信**：拿起、翻到背面，再拖到月灯上，隐墨显出日期 `7 · 1 · 4`，并掉落半枚星形封蜡。
4. **日期邮戳机**：将三个滚轮调到隐墨日期并压下手柄，得到一张带孔星图薄片。
5. **墙上星图**：旋转薄片并覆盖墙图，让孔洞套住七颗星，打开暗格并获得另一半星形封蜡。
6. **星形钥匙**：将两半封蜡拖到一起组成钥匙，插入投递窗；最后把原退信投入夜空。

## 剧情信息

- 值班记录暗示邮局曾经有另一位夜班员，但名字被剪掉。
- 退信并非“无人签收”，而是收件人尚未愿意记起。
- 结尾收件人栏浮现“给还记得的人”，为后续章节保留身份悬念。

## 视觉规则

- 原创 3D 羊毛毡、针毡、手工缝线与微缩定格动画质感。
- 主色为午夜靛蓝、灰紫、旧玫瑰和暖黄；机关成功后增加薰衣草紫光。
- UI 像压在桌边的深色毛毡标签，避免黑白极简和任何相似树枝/字母构图。
- 横屏为右侧窄栏，竖屏为底部物品抽屉；场景始终可操作，不强制旋转。
